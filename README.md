# متجر مودة (MODA Store) 👕✨

متجر إلكتروني عصري لبيع الملابس والأزياء، مصمم واجهات مستخدم جذابة ومتجاوبة بالكامل مع جميع الشاشات.

## 🚀 المميزات

- **واجهة عصرية**: تصميم أنيق يعتمد على الهوية البصرية لمحلات الأزياء العالمية.
- **متجاوب بالكامل**: يعمل بسلاسة على أجهزة الكمبيوتر، الأجهزة اللوحية، والهواتف الذكية.
- **سلايدر احترافي**: يدعم اللمس (Touch Swipe) مع نقاط مؤشر وتغيير تلقائي.
- **تأثيرات حركية**: تأثير كتابة (Typing Effect) وتلاشي للصور (Fade-in) عند التحميل.
- **تحسين الأداء**: استخدام خاصية Lazy Loading لتحميل الصور لضمان سرعة فائقة.
- **قائمة جانبية (Drawer Menu)**: مخصصة لمستخدمي الجوال لسهولة التنقل.

## 🛠️ التقنيات المستخدمة

- **HTML5**: لهيكلة صفحات الموقع.
- **CSS3**: للتنسيق والرسوم المتحركة (Animations).
- **JavaScript**: للتحكم في السلايدر، القائمة الجانبية، وتفاعلات المستخدم.
- **Google Fonts**: خط Cairo العربي.

## 📁 هيكل المشروع

- `index.html`: الصفحة الرئيسية.
- `products.html`: صفحة استعراض المنتجات مع الفلاتر.
- `product-detail.html`: صفحة تفاصيل المنتج.
- `cart.html`: سلة المشتريات.
- `checkout.html`: صفحة إتمام الدفع.
- `style.css`: ملف التنسيقات الشامل.
- `main.js`: ملف البرمجة والتفاعلات.

## 💻 كيف تشغل المشروع؟

1. قم بتحميل الملفات.
2. افتح ملف `index.html` في أي متصفح.
